# Implementation milestones

1. Foundation, documentation, Room schema, navigation, and protocol feasibility tests.
2. Recipe library with in-place editing, archive/delete, and JSON interchange.
3. Fuji JPEG MakerNote extraction, ranked matching, and segment-preserving IPTC/XMP tagging.
4. Android USB-host PTP conversion and the multi-recipe comparison workflow.
5. Unit/golden tests plus physical S23 FE/Fuji camera acceptance tests.

Physical acceptance requires original Fuji JPEG fixtures, a same-body RAF, USB-C data cable, and the camera in USB RAW CONVERSION mode.
